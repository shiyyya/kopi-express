# Kopi Café System

## Description
Web-based café management system for **Kopi Café**. This project replaces manual input processes with a digital platform to streamline customer ordering, staff operations, and owner reporting. Built with HTML, CSS, JavaScript, PHP, and MySQL.

## Features
- **Customer Module:** Login/Registration, menu browsing, cart & checkout, order status, promo codes, branch selection, payment via Cash or QR/GCash.  
- **Staff Module:** Order confirmation, inventory updates, sales reports.  
- **Owner Module:** Inventory management, branch synchronization, consolidated sales reports.  

## Tech Stack
- Front-end: HTML, CSS, JavaScript  
- Back-end: PHP  
- Database: MySQL  

## Limitations
- Payment limited to Cash and QR/GCash (no card integration).  
- Pick-up only (no delivery logistics).  
- Coverage limited to Pandi branches (Bunsuran, Poblacion, Siling Bata).  
- No ratings/reviews or advanced loyalty programs.  
- No third-party app integration (GrabFood, Foodpanda).
